  # Reactogenic

  A next-generation UI framework built on React.

  [Website](https://reactogenic.dev) •
  [Repository](https://github.com/reactogenic/reactogenic) •
  [Discussions](https://github.com/reactogenic/reactogenic/discussions)

  <br>
</div>

Reactogenic is a complete framework rather than a collection of libraries: the language, the compiler, the components and the routing are designed together and ship as one.

| Pillar | What it is |
| --- | --- |
| **Extended TSX** | A superset of React's TSX syntax, purpose-built for the framework. |
| **Compiler** | Reactogenic's own compiler, which understands the extended syntax and turns it into production output. |
| **Design system** | A first-party, UIKit-style set of components and primitives, so apps start from a coherent foundation. |
| **Router** | A built-in router designed alongside the compiler and components, not bolted on. |

> [!NOTE]
> Reactogenic is under active development and has not been released yet. APIs, syntax and package names are all subject to change.
